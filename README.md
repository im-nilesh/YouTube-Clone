# MERN YouTube Clone

A full-stack YouTube Clone built with the MERN stack as a capstone
project. The application supports authentication, channel creation,
video uploads, comments, likes/dislikes, search, category filtering, and
a responsive user interface.

## Features

### Authentication

- User registration and login
- JWT authentication
- Protected routes
- Persistent login

### Channels

- Create a channel
- View your own channel
- View other channels
- Channel logo, banner and subscriber count

### Videos

- Upload, edit and delete videos
- Watch videos
- Suggested videos
- Search videos
- Category filtering
- View counts

### Comments

- Add comments
- Edit comments
- Delete comments

### Engagement

- Like / Dislike videos

### User Interface

- Responsive design
- Sidebar navigation
- Search bar
- 404 page
- Scroll-to-top navigation
- Form validation

## Tech Stack

### Frontend

- React
- Vite
- React Router
- Context API
- Axios
- React Icons
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

The seed script populates:
